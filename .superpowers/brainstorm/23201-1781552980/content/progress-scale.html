How should topic progress be tracked?

Each topic needs a scale to record how well you know it

A

Named stages

Not started → In progress → Practiced → Mastered. Clear intent, easy to set manually after a session.

B

1–5 confidence rating

After each session you rate your confidence on this topic. Averages over time to show a trend.

C

Percentage (0–100%)

You set a % after each session. More granular but also more friction to update accurately.
